# 08 — Interactive report and user-controlled action workspace

**What to build:** A consumer receives the complete structured report: scope and limitations, overview, prioritized findings, account comparisons, identity/inquiry review, education, sources/methodology, and a verification checklist. The consumer can recognize, dismiss with a reason, correct, add notes, gather documents, and track proportionate next steps without automatic communications or deletion promises.

**Blocked by:** 07 — Deterministic evidence-linked analysis.

**Status:** ready-for-agent

- [ ] The report displays scope, supported bureaus/providers, report dates, jurisdiction, processing quality, unsupported sections, and product limitations.
- [ ] The report displays an overview of account categories, open/closed counts, collections, inquiries, valid utilization data, and displayed score/model information without predicting outcomes.
- [ ] Priority findings are ordered by consumer impact, certainty, and actionability and expose evidence navigation.
- [ ] Account comparisons show bureau-specific values and update-date context side by side.
- [ ] Identity and inquiry review distinguishes recognition questions, unresolved items, and identity-theft education from general credit education.
- [ ] Educational modules explain relevant credit concepts and distinguish accurate negative information from potential verification opportunities.
- [ ] Each finding exposes limitations, alternative explanations, documents/facts to verify, and a proportionate suggested next step.
- [ ] The consumer can recognize, dismiss with a reason, correct data, add notes, gather documents, and track checklist status.
- [ ] The product does not automatically send communications, generate mass disputes, promise deletion, or state a guaranteed score outcome.
- [ ] Core report and action flows are keyboard usable, readable, and compatible with the planned accessibility checks.
