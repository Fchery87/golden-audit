# One-state launch selection memo

> **Status:** Product/governance selection memo. This is not legal advice.

## Decision
For the current **one-state free pilot** posture, the recommended provisional launch state is:

## **California**

## Why California is the strongest current choice

This is **not** because California is the easiest or least regulated state. It is because California is the state the repo currently understands best.

### 1) The repo already centers California in multiple places
- `docs/legal-pre-mortem-brief.md` is framed as a **California pilot** brief.
- `docs/pilot-readiness.md` currently refers to the initial **California-only controlled pilot**.
- ticket 12 already requires California-specific review items, including California Credit Services Act review for any paid model.

### 2) Choosing California minimizes internal inconsistency
If we choose another state right now, we create a mismatch between:
- the pilot-readiness document,
- the legal pre-mortem framing,
- the existing human-gated backlog,
- and the strongest state-specific documentation already in the repo.

### 3) The point of the current decision is bounded scope, not easy-law assumptions
The safest recommendation in the repo is:
- one reviewed state,
- free pilot,
- analysis-only,
- educational,
- consumer-uploaded,
- consumer-only delivery.

California fits that posture because it is the state where the repo already has the most explicit legal boundary work, even though it remains a high-scrutiny state.

## What this decision does **not** mean
This memo does **not** mean:
- California is low-risk,
- California is formally cleared,
- paid launch is approved,
- nationwide expansion is supported,
- the product is outside all California credit-services or privacy questions.

It means only:
- if we must choose **one** state now for the current rollout posture,
- California is the most coherent choice given the repo’s current evidence trail.

## Conditions on this recommendation
This recommendation only holds if the pilot remains:
- free,
- invite-only,
- analysis-only,
- educational,
- consumer-uploaded,
- consumer-only,
- without disputes, bureau contact, furnisher contact, or legal conclusions.

If those conditions change, this selection should be re-opened.

## Operational consequences
If California is adopted as the provisional launch state:
- onboarding copy should explicitly say the pilot is currently available only to California consumers in the approved scope,
- approval/governance records should capture the selected launch state explicitly,
- unsupported states should be blocked from proceeding,
- no broad U.S. availability language should appear anywhere in the product or marketing surfaces.
