# Human Approval & Rollout Scaffolding

This folder is for preparing approval packets, evidence references, and rollout decisions without pretending those approvals already exist.

## Current posture
- legal, privacy, security, accessibility, operations, and vendor approval are still human-gated
- rollout remains state-by-state, not nationwide
- any production release candidate still needs real sign-off
